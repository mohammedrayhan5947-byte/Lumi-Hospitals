# Lumi Hospital: build conventions

Stack: Vite MPA, vanilla ES modules, GSAP (ScrollTrigger, SplitText, Flip), Lenis. The dev server runs at http://localhost:5173.

## Files
- `src/data/site.js`: **all content** (BIZ, NAV, DEPARTMENTS, DOCTORS, PACKAGES, JOURNEY, TESTIMONIALS, FAQ, SEASONS, POSTS). Never hard-code facts in pages. Read from here. Missing facts stay as TODO in data, never invented in markup.
- `src/js/core.js`: `boot(async () => { render into <main> })`. It handles theme, layout, forms, accordions and motion. Call it once per entry.
- `src/js/render.js`: helpers: `$ $$ esc inr tel wa params deptById doctorById doctorsIn initials fmtDate pad icon btn media deptCard doctorCard packageCard postCard secHead pageHero accordion`.
- `src/js/motion.js`: `gsap, ScrollTrigger, refreshMotion(root)`. Call `refreshMotion(el)` after re-rendering content (filters).
- `src/js/theme.js`: `motionAllowed()`. Guard every custom animation with it.
- `src/js/forms.js`: `<form data-wa="Title">` sends to WhatsApp, `<button type="button" data-send="email">` sends by email, and `.form-done[hidden]` is the success message.
- Page entry: `src/js/pages/<entry>.js`, which imports its own CSS `src/css/pages/<entry>.css`.
- HTML shells are generated by `node scripts/pages.mjs`. Don't hand-edit the root `.html` files.
- QA: `node scripts/shot.mjs <page.html?query> <width> <light|dark> <scrollY...|full>` writes PNGs to `.shots/` and prints console errors.

**Shared files (core.js, render.js, motion.js, layout.js, theme.js, tokens.css, base.css, components.css, site.js) belong to the lead. Don't edit them.** If you need a shared change, put it in your final report.

## Declarative motion hooks (they work on any page automatically)
`data-reveal` (rise; `="fade"` or `="scale"`), `data-split` (headline line mask), `data-count="N"`, `data-parallax="0.1"`, `data-magnetic`, `.tile` (cursor spotlight), `.marquee > .marquee-track[data-speed][data-dir=right]`, `[data-instant]` on an ancestor makes a split play immediately instead of on scroll.

## Design language: editorial, calm, confident. Not "template-y".
- Colour comes only from tokens: `--paper --paper-2 --surface --surface-2 --ink --ink-2 --muted --line --line-2 --accent --on-accent --accent-soft --accent-line --danger --hero-bg`. No raw hex except inside the dark `--hero-bg` sections. Everything must work in light, dark, all 4 accents, the seasonal accent, high contrast and large text.
- Type: `h1/h2` are display (Bricolage). Wrap **one** emphasis word in `<em>`, which renders in Instrument Serif italic in the accent colour. Labels use `.label` (mono, uppercase). Section intros use `secHead("01", "Label", "Title with <em>word</em>", aside)`.
- Layout: `.container`, `.section` (`.section--alt` for alternating bands, `.section--tight`), `.grid .g2/.g3/.g4`, generous whitespace, asymmetric splits. Cards are `.tile`.
- Buttons: `btn(href, label, "accent"|"line"|"glass"|"danger"|"", { ic, sm })`.
- Images: always `media(src, alt, fallback)`, which falls back to the branded `.ph-mono` placeholder until real photos arrive. Wrap it in an element with `.ph` and an aspect-ratio.
- Avoid: emoji, stock "medical blue" gradients, centred-everything layouts, generic three-icon feature rows, drop shadows on everything, lorem ipsum, fake reviews, ratings or accreditations.
- Motion: purposeful and smooth (expo.out, 0.8–1.2s). One signature interaction per page beyond the shared hooks. Never block content, and everything must stay readable with motion off.
- Accessibility: semantic landmarks, labels on every input, `aria-*` on custom controls, visible focus, 44px minimum hit targets, AA contrast. Must work at 360px wide with no horizontal scroll.
- Internal links are root-absolute: `/doctors.html`, `/doctor.html?id=…`, `/department.html?id=…`, `/post.html?id=…`, `/appointment.html?dept=…&doctor=…&package=…`.
